# Как работает бот @photoimpulsbot

## Для участников конференции

1. **Заход в бота**  
   Участник открывает бота @photoimpulsbot и нажимает **Start** (или пишет `/start`). Команда **`/menu`** открывает главное меню с разделами.

2. **Приветствие**  
   Бот приветствует (при желании — с картинкой) и просит подписаться на канал конференции. Показывает кнопку **«Подписаться на канал»**.

3. **Подписка на канал**  
   Участник нажимает кнопку, переходит в канал и подписывается. Возвращается в бота и нажимает **«Я подписался»**.

4. **Проверка подписки**  
   Бот проверяет подписку. Если всё ок — пишет «Отлично! Спасибо, что с нами!» и открывает **Фото-Центр**.

5. **Фото-Центр**  
   Бот объясняет: фото появятся не сразу, когда альбом будет готов — придёт уведомление. Показывает три кнопки: **День 1 • 9 фев**, **День 2 • 10 фев**, **День 3 • 11 фев**.

6. **Выбор дня**  
   Участник может выбрать **несколько дней** (например, День 1 и День 2). После выбора нажимает **«Добавить ещё день»**, если нужно подписаться на другие дни. Бот подтверждает: «Вы подписались на уведомления для: День 1, День 2». У уже выбранных дней отображается галочка ✓.

7. **Главное меню** (`/menu`)  
   Быстрый доступ: **Мои дни**, **Специальность**, **Фото-центр**, **Программа**, **Помощь**, **О боте**. Кнопка **«В меню»** возвращает в главное меню.

8. **Ожидание**  
   Участник ждёт. Никакой ссылки сразу бот не даёт.

9. **Уведомление о готовности фото**  
   Когда вы (админ) отправляете боту команду `/notify_day1` (или 2, или 3), бот **автоматически** отправляет всем, кто подписан на этот день, сообщение: «Фото готовы!» и кнопку **«Открыть альбом Дня N на Яндекс.Диске»**. По нажатию открывается ваша папка на Яндекс.Диске с фото этого дня.

## Для вас (администратора)

1. **Запуск бота**  
   В терминале: `cd C:\Users\julia\photoimpuls-bot`, затем `py bot.py`. Окно не закрывайте, пока нужны уведомления.

2. **В течение дня**  
   Участники заходят в бота, подписываются на канал и выбирают день(и). Бот сохраняет в базу: кто на какой день подписан.

3. **Когда альбом дня готов**  
   Вы загружаете фото в нужную папку на Яндекс.Диске (та, что указана в `.env` для этого дня). Открываете бота @photoimpulsbot в Telegram и пишете команду:

   **По одному дню:**
   - **`/notify_day1`** — для Дня 1 (9 февраля),
   - **`/notify_day2`** — для Дня 2 (10 февраля),
   - **`/notify_day3`** — для Дня 3 (11 февраля).

   **Несколько дней сразу (одно сообщение со всеми ссылками):**
   - **`/notify_ready 1 2 3`** — фото готовы для всех трёх дней,
   - **`/notify_ready 1 2`** — фото готовы для Дня 1 и 2,
   - **`/notify_ready 2`** — только День 2.

4. **Что делает бот**  
   Бот находит в базе всех, кто подписан на уведомления за нужный день (или дни), и **автоматически** отправляет каждому сообщение со ссылкой на альбом. При `/notify_ready` пользователь получает **одно сообщение** с кнопками только для тех дней, которые он выбрал.

**Итого:** вы один раз отправляете команду боту — рассылка идёт всем подписавшимся автоматически.

## Настройка (.env)

- `CHANNEL_ID` — ID канала (узнать: @getidsbot в канале).
- `YANDEX_DAY1_LINK`, `YANDEX_DAY2_LINK`, `YANDEX_DAY3_LINK` — публичные ссылки на папки на Яндекс.Диске для каждого дня.
- `ADMIN_IDS` — ваш Telegram ID (и других админов через запятую). Только эти пользователи могут отправлять команды уведомлений. ID узнать: @userinfobot.
- `WELCOME_IMAGE`, `IMAGE_SUBSCRIBE`, `IMAGE_SPECIALTY`, `IMAGE_PHOTO_CENTER` — пути к картинкам или URL. См. папку `images/` и `.env.example`.

Бот должен быть администратором в канале. Ссылки на Яндекс.Диск — с доступом по ссылке.

## Google Sheets (Подписки и Статус)

Бот записывает данные в Google Таблицу: листы **Подписки** и **Статус**.

### Способ 1: Web App (без Google Cloud Console) — рекомендуем

1. Откройте [sheets.google.com](https://sheets.google.com) и создайте **новую таблицу**.
2. Меню **Расширения** → **Apps Script**.
3. Удалите весь код в редакторе и вставьте код из файла **`google-sheets-script.js`** (в папке бота).
4. Сохраните (Ctrl+S).
5. Нажмите **Развернуть** → **Новое развертывание** → значок шестерёнки → **Веб-приложение**.
6. Укажите:
   - **Выполнять от имени:** Я
   - **У кого есть доступ:** Все пользователи
7. Нажмите **Развернуть**. Скопируйте **URL веб-приложения**.
8. В `.env` добавьте строку:
   ```
   SHEETS_WEBAPP_URL=скопированный_url
   ```

Листы «Подписки» и «Статус» создадутся автоматически при первой записи от бота.

## Что сделано по заданию

### 1. Подписки — данные в Google Таблицу (лист «Подписки»)

Бот записывает в лист **Подписки**:
- `timestamp` — дата и время
- `user_id` — Telegram ID
- `username` — логин в Telegram
- `first_name` — имя
- `specialty_id` — ID выбранной специальности (1–6)
- `specialty_name` — название специальности (Неврология, Терапия и т.д.)
- `notify_days` — на какие дни подписан (День 1, День 2, День 3)

Запись идёт при: `/start`, проверке подписки, выборе специальности, выборе дня.

---

### 2. Статус — переменные прохода (лист «Статус»)

Бот записывает в лист **Статус**:
- `timestamp` — дата и время
- `user_id` — Telegram ID
- `status` — тип события
- `value` — дополнительное значение (при необходимости)

**Статусы:**
- `зашел` — пользователь нажал /start
- `подписался` — прошёл проверку подписки на канал
- `сказал специальность` — выбрал специальность (value = название)
- `выбрал день` — выбрал день конференции (value = День 1 / День 2 / День 3)

---

### 3. Несколько дней — выбор фото за 2 и больше дней

- Пользователь может выбрать **несколько дней** (День 1, День 2, День 3).
- Кнопка **«Добавить ещё день»** — после выбора первого дня можно добавить второй, третий.
- Галочки ✓ показывают уже выбранные дни.
- Команда **`/notify_ready 1 2 3`** — одно сообщение со ссылками на все выбранные дни.
- Пользователь получает кнопки только для тех дней, которые он выбрал.

---

### 4. Место и кнопка «Программа»

- **Место (PLACE)** — переменная в `.env`, пока не используется в сообщениях бота. Можно будет подключить позже.
- **Кнопка «Программа»** — добавлена в меню выбора дней. Ведёт на сайт с расписанием конгресса.  
  В `.env` задаётся: `PROGRAM_SCHEDULE_URL=https://...`

## Обновления (31.01.2025)

### Улучшен выбор нескольких дней (Фото-Центр)

- **Можно выбрать несколько дней** — участник нажимает День 1, затем «Добавить ещё день» и выбирает День 2. Подтверждение показывает: «Вы подписались на: День 1, День 2».
- **Кнопка «Добавить ещё день»** вместо «Изменить выбор дня» — понятнее, что можно добавлять дни.
- **Галочки ✓** — при повторном нажатии «Добавить ещё день» у уже выбранных дней отображается ✓.

### Команда `/notify_ready` — одно сообщение для нескольких дней

- **`/notify_ready 1 2 3`** — отправить всем подписчикам одно сообщение со ссылками на альбомы тех дней, которые они выбрали.
- Участник, выбравший День 1 и День 2, получит одно сообщение с двумя кнопками: «День 1 • 9 фев» и «День 2 • 10 фев».
- Команды `/notify_day1`, `/notify_day2`, `/notify_day3` по-прежнему работают — можно отправлять по одному дню.
