# Telegram Bot для конференции "Вейновские чтения"

Telegram-бот для автоматизации работы с участниками конференции: подписки на канал, выбор специальности, уведомления о готовности фотографий, интеграция с Google Sheets и веб-сайтом расписания.

## 🚀 Основные возможности

- ✅ **Проверка подписки на канал** — автоматическая проверка подписки участников
- ✅ **Выбор специальности** — участники указывают свою специальность (сохраняется в БД)
- ✅ **Выбор дней конференции** — подписка на уведомления о готовности фото для нескольких дней
- ✅ **Автоматические уведомления** — массовая рассылка ссылок на альбомы Яндекс.Диска
- ✅ **Интеграция с Google Sheets** — автоматическая запись данных о подписках и статусах
- ✅ **Веб-сайт расписания** — React-приложение с расписанием конференции
- ✅ **Яндекс.Метрика** — отслеживание посещений сайта расписания
- ✅ **SQLite база данных** — хранение данных пользователей

## 🛠 Технологии

- **Python 3.9+** — основной язык
- **python-telegram-bot** — библиотека для работы с Telegram Bot API
- **SQLite** — база данных для хранения пользователей
- **Google Apps Script** — интеграция с Google Sheets
- **React + TypeScript + Vite** — веб-сайт расписания
- **Tailwind CSS** — стилизация сайта
- **Яндекс.Метрика** — аналитика посещений

## 🔧 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/yourusername/photoimpuls-bot.git
cd photoimpuls-bot
```

### 2. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```env
# Telegram Bot
BOT_TOKEN=your_bot_token_here
CHANNEL_ID=your_channel_id
CHANNEL_INVITE_LINK=https://t.me/your_channel

# Яндекс.Диск (ссылки на альбомы)
YANDEX_DAY1_LINK=https://disk.yandex.ru/...
YANDEX_DAY2_LINK=https://disk.yandex.ru/...
YANDEX_DAY3_LINK=https://disk.yandex.ru/...

# Администраторы (через запятую)
ADMIN_IDS=123456789,987654321

# Google Sheets (опционально)
SHEETS_WEBAPP_URL=https://script.google.com/...

# Изображения (опционально)
WELCOME_IMAGE=images/добро пожаловать.jpg
IMAGE_SUBSCRIBE=images/подт подписку.jpg
IMAGE_PHOTO_CENTER=images/указать день.jpg

# Сайт расписания
PROGRAM_SCHEDULE_URL=http://your-domain.com:8080/
```

### 4. Настройка Google Sheets (опционально)

1. Создайте таблицу в Google Sheets
2. Расширения → Apps Script
3. Вставьте код из `google-sheets-script.js`
4. Разверните как веб-приложение
5. Скопируйте URL в `.env`

### 5. Запуск бота

```bash
python bot.py
```

## 📱 Использование

### Для участников

1. Открыть бота `/start`
2. Выбрать специальность
3. Подписаться на канал
4. Выбрать дни для получения уведомлений о фото
5. Получить уведомление, когда фото готовы

### Для администраторов

- `/notify_day1` — уведомить о готовности фото Дня 1
- `/notify_day2` — уведомить о готовности фото Дня 2
- `/notify_day3` — уведомить о готовности фото Дня 3
- `/notify_ready 1 2 3` — уведомить о готовности нескольких дней сразу

## 🌐 Веб-сайт расписания

В папке `schedule/` находится React-приложение с расписанием конференции.

### Установка и запуск

```bash
cd schedule
npm install
npm run dev      # Разработка
npm run build    # Сборка для продакшена
```

### Особенности

- Подсветка важных событий (жёлтая рамка)
- Адаптивный дизайн
- Интеграция с Яндекс.Метрикой
- Футер с логотипом агентства

## 📊 База данных

Бот использует SQLite для хранения:
- Данных пользователей (ID, username, подписки)
- Выбранных специальностей
- Выбранных дней для уведомлений

## 🔒 Безопасность

- Все секретные данные хранятся в `.env` (не коммитится в Git)
- Токены бота не хранятся в коде
- Проверка прав администратора перед выполнением команд
