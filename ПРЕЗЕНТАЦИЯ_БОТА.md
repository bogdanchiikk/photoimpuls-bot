# 📱 Telegram-бот @photoimpulsbot
## Фото-Центр конференции "Вейновские чтения"

---

## 🎯 Назначение бота

Автоматизированная система для:
- ✅ Регистрации участников конференции
- 📸 Распространения фотографий с мероприятия
- 🔔 Уведомлений о готовности фото-альбомов
- 📊 Сбора статистики и аналитики

---

## 🚀 Основной функционал

### 1. **Простой пользовательский flow**

```
/start → Выбор специальности → Подписка на канал → Доступ к фото
```

**Шаги:**
1. Пользователь запускает бота (`/start`)
2. Выбирает свою специальность из списка (Невролог, Психиатр, Реабилитолог, Психотерапевт, Другое)
3. Подписывается на канал конференции
4. Получает доступ к кнопкам с ссылками на фото по дням

### 2. **Умная проверка подписки**

- ✅ Автоматическая проверка подписки через Telegram API
- 🔄 Кнопка "Я подписался" для подтверждения
- 🚫 Блокировка доступа к фото без подписки

### 3. **Выбор дней для уведомлений**

- 📅 Пользователь может выбрать **несколько дней** (День 1, День 2, День 3)
- ✅ Галочки показывают уже выбранные дни
- ➕ Кнопка "Добавить ещё день" для выбора дополнительных дней

## 💡 Ключевые фишки

### 🎨 **Визуальное оформление**

- 🖼️ Поддержка изображений на разных этапах:
  - Приветственное изображение (`WELCOME_IMAGE`)
  - Изображение при запросе подписки (`IMAGE_SUBSCRIBE`)
  - Изображение в фото-центре (`IMAGE_PHOTO_CENTER`)
- 📱 Адаптивные inline-кнопки с эмодзи
- 🎯 Чистый и понятный интерфейс

### 🔐 **Безопасность и права доступа**

- 👤 **Персонализированные команды:**
  - Обычные пользователи видят: `/start`, `/check`
  - Администраторы видят дополнительно: `/notify_day1`, `/notify_day2`, `/notify_day3`, `/notify_ready`, `/upload_links`
- 🔒 Админские команды доступны только указанным пользователям (`ADMIN_IDS`)

### 📊 **Интеграция с Google Sheets**

**Автоматическое логирование:**
- 📝 **Лист "Подписки":**
  - ID пользователя, username, имя
  - Выбранная специальность
  - Выбранные дни для уведомлений
  - Timestamp всех действий

- 📈 **Лист "Статус":**
  - События: "зашёл", "подписался", "сказал специальность", "выбрал день"
  - Полная история взаимодействий пользователя с ботом

**Преимущества:**
- ✅ Не требует Google Cloud Console
- ✅ Работает через Google Apps Script Web App
- ✅ Автоматическое создание листов при первом использовании

### 🔔 **Умная система уведомлений**

#### Для одного дня:
```
/notify_day1  → Уведомление всем, кто выбрал День 1
/notify_day2  → Уведомление всем, кто выбрал День 2
/notify_day3  → Уведомление всем, кто выбрал День 3
```

#### Для нескольких дней одновременно:
```
/notify_ready 1 2 3  → Одно сообщение со ссылками на все выбранные дни
```

**Как это работает:**
- Бот находит всех пользователей, выбравших указанные дни
- Отправляет **персонализированное сообщение** с кнопками только для тех дней, которые выбрал конкретный пользователь
- Если пользователь выбрал День 1 и День 2, он получит кнопки только для этих дней

### 📁 **Интеграция с Яндекс.Диском**

- 🔗 Публичные ссылки для просмотра фото (`YANDEX_DAYx_LINK`)
- 📤 Отдельные ссылки для загрузки фотографом (`YANDEX_DAYx_UPLOAD_LINK`)
- 🎯 Прямые кнопки-ссылки в интерфейсе бота

### 💾 **База данных SQLite**

- Хранение данных пользователей локально
- Быстрый доступ к информации
- Отслеживание выбранных дней и статуса подписки

## 🛠️ Технические особенности

### ⚡ **Производительность**

- 🚀 **Асинхронная обработка** (asyncio)
- ⏱️ **Неблокирующие операции:**
  - Сначала отправка ответа пользователю
  - Затем запись в Google Sheets (в фоне)
- 🔄 **Таймауты:** 30 секунд на подключение, чтение, запись

### 🛡️ **Обработка ошибок**

- ✅ Graceful degradation при недоступности Google Sheets
- 🔄 Fallback на локальные тексты при отсутствии `texts.py`
- 📝 Подробное логирование всех операций
- ⚠️ Предупреждения при отсутствии конфигурации

### 🌐 **Многоязычность и кодировки**

- ✅ Поддержка UTF-8, Latin-1, CP1251 для `.env` файлов
- 🔤 Unicode escape sequences для совместимости с сервером
- 📱 Корректное отображение русских текстов в Telegram

### 🎛️ **Гибкая конфигурация**

Все настройки через `.env`:
- Токен бота
- ID канала
- Ссылки на Яндекс.Диск
- ID администраторов
- Пути к изображениям
- URL Google Sheets Web App

## 🎯 Сценарии использования

### Сценарий 1: Участник конференции

1. Открывает бота → выбирает специальность
2. Подписывается на канал → получает доступ к фото-центру
3. Выбирает дни конференции (например, День 1 и День 2)
4. Ждёт уведомления
5. Получает сообщение "Фото готовы!" с кнопками-ссылками
6. Переходит на Яндекс.Диск и скачивает фото

### Сценарий 2: Организатор конференции

1. Загружает фото в папку на Яндекс.Диске
2. Отправляет боту команду `/notify_day1`
3. Бот автоматически уведомляет всех, кто выбрал День 1
4. Просматривает статистику в Google Sheets

### Сценарий 3: Фотограф

1. Получает ссылки для загрузки через `/upload_links`
2. Загружает фото в соответствующие папки
3. Сообщает организатору о готовности

## 🔧 Архитектура

```
bot.py (основной файл)
├── database.py (SQLite база данных)
├── sheets.py (интеграция с Google Sheets)
├── texts.py (текстовые сообщения)
└── .env (конфигурация)
```

**Основные компоненты:**
- **Handlers:** обработка команд и callback-запросов
- **Keyboards:** генерация inline-кнопок
- **Database:** работа с SQLite
- **Sheets:** асинхронная запись в Google Sheets
- **Utils:** проверка подписки, обработка изображений
