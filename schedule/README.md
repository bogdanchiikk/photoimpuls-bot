# 📅 Сайт с расписанием конференции

## Размещение файлов

Поместите файлы сайта с расписанием в эту папку (`schedule/`).

## Развертывание на сервере

### Вариант 1: Простой статический сайт (HTML/CSS/JS)

Если у вас есть файлы `index.html`, `style.css`, `script.js` и т.д.:

1. Загрузите все файлы в папку `schedule/` на сервере
2. Настройте веб-сервер (nginx/apache) для обслуживания этой папки
3. Или используйте простой Python HTTP-сервер:

```bash
cd ~/photoimpuls-bot/schedule
python3 -m http.server 8080
```

### Вариант 2: Через nginx (рекомендуется)

Добавьте в конфигурацию nginx:

```nginx
server {
    listen 80;
    server_name ваш-домен.ru;
    
    location /schedule {
        alias /root/photoimpuls-bot/schedule;
        index index.html;
    }
}
```

### Вариант 3: Рядом с ботом (если не получится развернуть отдельно)

Можно оставить файлы здесь, но они не будут автоматически доступны через веб. Нужна отдельная настройка веб-сервера.

---

**Примечание:** Если развертывание сайта не критично, можно обойтись без него — бот работает независимо.
