# Изменения на сайте расписания

Эти правки нужно сделать **на сервере** в папке `/root/photoimpuls-bot/schedule/` (в исходниках в `src/`), затем заново собрать проект и перезапустить сервис.

---

## 1. Ссылка на расписание в боте

Уже сделано: в боте задана ссылка по умолчанию `http://185.198.152.146:8080/`.  
В меню бота есть кнопка «📅 Расписание» — она ведёт на сайт.  
При необходимости можно переопределить в `.env`:  
`PROGRAM_SCHEDULE_URL=http://185.198.152.146:8080/`

## 2. Подсветить событие жёлтой рамочкой

Нужно событие:
- **9 февраля**, 12:00–13:00  
- **Зал «Мозговой парус»**  
- «Клиническая значимость дефицита витаминов группы B при метаболическом синдроме: результаты исследования»  
- Екушева Е.В., Шишкова В.Н.

В данных оно имеет **cell_id: `D1_1200_H5`**.

### Что сделать на сервере

1. Зайти по SSH и перейти в папку с исходниками:
   ```bash
   cd /root/photoimpuls-bot/schedule/src
   ```

2. Найти компонент, который рисует одну карточку события (поиск по `cell_id` или по полям `title`, `hall`):
   ```bash
   grep -r "cell_id\|event_type\|hall" --include="*.tsx" --include="*.jsx" .
   ```

3. В этом компоненте у корневого элемента карточки (например, `div` или `article`) добавить условный класс для подсветки. Пример для Tailwind:
   - найдите разметку одной карточки (что-то вроде `<div className="...">` или `<article ...>`);
   - добавьте к классу условие, например:
   ```jsx
   className={`bg-white rounded-lg shadow-md p-6 border-l-4 border-yellow-400 ${data.cell_id === 'D1_1200_H5' ? 'ring-4 ring-yellow-400' : ''}`}
   ```
   или только жёлтую рамку:
   ```jsx
   className={`... ${data.cell_id === 'D1_1200_H5' ? 'ring-4 ring-yellow-400 border-2 border-yellow-400' : ''}`}
   ```
   Если используете не Tailwind, а обычный CSS:
   ```jsx
   style={data.cell_id === 'D1_1200_H5' ? { border: '4px solid #facc15', boxShadow: '0 0 0 2px #facc15' } : {}}
   ```
   и добавьте в ваш CSS-файл при необходимости класс для выделения.

4. Сохранить файл, пересобрать и перезапустить:
   ```bash
   cd /root/photoimpuls-bot/schedule
   npm run build
   sudo systemctl restart schedule
   ```

## 3. Футер внизу сайта: «Создано агентством Кафедра» и логотип

### Куда положить картинку логотипа

- На сервере: скопировать файл (например, `kafedra-logo.png`) в папку **`schedule/public/`**.
- Локально (если собираете у себя): в папку **`schedule/public/`** того же проекта.

Файлы из `public/` при сборке попадают в корень сайта, поэтому логотип будет доступен по адресу: **`/kafedra-logo.png`** (или как вы назовёте файл).

Если папки `public/` нет — создайте её рядом с `src/`:
```bash
mkdir -p /root/photoimpuls-bot/schedule/public
# затем скопировать туда логотип, например:
# (через WinSCP перетащить файл в schedule/public/)
```

### Где вывести футер в коде

1. Открыть главный компонент приложения (часто `src/App.tsx` или тот, где рендерится вся страница расписания).

2. Внизу разметки, после основного контента (после списка событий), добавить блок футера, например:

   ```jsx
   <footer className="mt-16 py-6 border-t border-gray-200 bg-white text-center text-gray-600 text-sm">
     <p className="mb-2">Создано агентством Кафедра</p>
     <img src="/kafedra-logo.png" alt="Кафедра" className="h-12 mx-auto" />
   </footer>
   ```

   Имя файла замените на своё (например, `logo.png` → `src="/logo.png"`).

3. Сохранить, снова выполнить на сервере:
   ```bash
   cd /root/photoimpuls-bot/schedule
   npm run build
   sudo systemctl restart schedule
   ```
